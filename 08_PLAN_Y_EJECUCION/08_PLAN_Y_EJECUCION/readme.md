# Plan y Ejecución

Esta carpeta contiene los documentos que explican cómo se está desarrollando el proyecto, qué decisiones se han tomado y cómo se ha usado IA de manera verificable.

## Contenido
- `preparacion_datos.md`: plan detallado de limpieza, transformación y exportación de datos.
- `uso_de_ia.md`: bitácora de uso de herramientas de IA durante el proyecto.

## Objetivo de esta carpeta
Garantizar trazabilidad, orden metodológico y evidencia de revisión humana sobre el trabajo realizado.
